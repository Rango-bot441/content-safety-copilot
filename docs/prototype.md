# 原型说明：Content Safety Copilot

## 1. 原型定位

Content Safety Copilot 当前是一个可交互 Web 原型，用于展示“创作者发布前内容安全辅助”的完整体验闭环。

线上体验地址：

https://content-safety-copilot.onrender.com

原型重点不是模拟真实审核系统，而是表达产品机制：

```text
输入内容 → 检测风险 → 解释原因 → 给出改写 → 发布前自查
```

## 2. 页面结构

当前版本为单页布局，分为左右两栏：

| 区域 | 作用 |
| --- | --- |
| 左侧：内容送检 | 用户输入待检测内容 |
| 右侧：AI 检测结果 | 展示风险等级、风险点、改写建议和自查清单 |

页面信息架构：

```text
Content Safety Copilot
├── 内容送检
│   ├── 内容垂类
│   ├── 账号粉丝量
│   ├── 视频标题 / 封面文案
│   ├── 口播稿 / 正文内容
│   ├── 评论区互动引导
│   ├── 开始安全检测
│   └── 换一个样例
└── AI 检测结果
    ├── 风险概览
    ├── 运营判断
    ├── 命中风险点
    ├── 表达改写建议
    ├── 修改后全文案
    └── 发布前自查清单
```

## 3. 核心交互流程

### 3.1 首次进入

用户进入页面后，右侧显示空状态说明：

```text
输入创作者准备发布的标题、口播稿和评论引导后，点击“开始安全检测”。
```

设计意图：

- 让用户理解工具用途。
- 不强制注册。
- 不需要复杂配置。

### 3.2 内容输入

用户填写：

- 内容垂类。
- 账号粉丝量。
- 标题 / 封面文案。
- 口播稿 / 正文内容。
- 评论区互动引导。

设计意图：

- 内容垂类帮助用户建立风险语境。
- 标题、正文、评论引导覆盖发布前最常见风险入口。
- 粉丝量用于表达账号阶段，但 MVP 暂不做差异化规则。

### 3.3 开始检测

用户点击“开始安全检测”后：

1. 按钮进入“分析中”状态。
2. 右侧展示加载态。
3. 约 1.8 秒后展示检测结果。

设计意图：

- 用短暂加载态模拟 AI 分析过程。
- 给用户明确反馈，避免误以为页面无响应。

### 3.4 结果概览

检测完成后，顶部展示四个核心结果：

| 卡片 | 含义 |
| --- | --- |
| 风险等级 | 高风险 / 中风险 / 低风险 |
| 命中风险点 | 当前内容命中的风险数量 |
| 可发布分 | 以分数表达风险程度 |
| 重点关注 | 最优先处理的风险类型 |

设计意图：

- 先给用户一个快速判断。
- 用“可发布分”降低抽象风险理解成本。
- 用“重点关注”指导下一步修改。

### 3.5 运营判断

系统用自然语言总结当前内容状态。

示例：

```text
当前内容存在 3 个风险点，其中包含高风险表达。建议优先处理确定性承诺、敏感垂类收益或疗效暗示，再进入发布流程。
```

设计意图：

- 模拟内容运营对创作者的判断口吻。
- 让结果更像协作建议，而不是冷冰冰的审核结论。

### 3.6 命中风险点

每个风险点展示：

- 风险类型。
- 风险原因。
- 修改建议。

设计意图：

- 帮用户知道具体错在哪里。
- 降低用户与运营/平台之间的沟通成本。

### 3.7 表达改写建议

系统按字段展示修改前后对比：

- 标题 / 封面文案。
- 口播稿 / 正文内容。
- 评论区互动引导。

变化内容用高亮标出。

设计意图：

- 用户能快速看到哪些词被改。
- 避免只给一段新文案，导致用户无法理解修改逻辑。

### 3.8 一键复制

用户点击“复制修改后全文案”后，可以复制完整安全版本。

设计意图：

- 缩短从检测到修改完成的路径。
- 让工具从“分析型工具”变成“可执行工具”。

### 3.9 发布前自查

结果底部展示发布前自查清单。

设计意图：

- 强调 AI 只是辅助，不替代人工判断。
- 帮创作者形成发布前复核习惯。

## 4. 状态设计

| 状态 | 触发条件 | 页面反馈 |
| --- | --- | --- |
| 空状态 | 首次进入或未检测 | 展示工具说明 |
| 空输入提示 | 用户未输入内容就点击检测 | 提示先输入标题、正文或评论引导 |
| 加载状态 | 点击检测后 | 按钮变为“分析中”，右侧显示加载动画 |
| 高风险结果 | 命中高风险规则 | 风险等级显示高风险，建议先改写再发布 |
| 中风险结果 | 只命中中风险规则 | 风险等级显示中风险，建议微调后发布 |
| 低风险结果 | 未命中明显风险 | 提示可进入发布复核 |
| 复制成功 | 点击复制按钮 | 按钮短暂显示“已复制” |

## 5. 样例设计

当前内置四个样例：

| 样例 | 垂类 | 目的 |
| --- | --- | --- |
| 教育培训 | 课程资料、学习模板、评论区打 1 | 展示夸大承诺和诱导互动 |
| 财经理财 | 收益翻倍、稳赚、无风险 | 展示财经高敏风险 |
| 健康养生 | 睡眠习惯、专业医生建议 | 展示低风险内容 |
| 泛知识 / 科普 | AI 选题效率 | 展示稳妥表达和边界说明 |

样例用于帮助使用者快速体验不同风险等级。

## 6. 原型边界

- 当前为纯前端原型，未接入真实 AI 模型。
- 当前规则写在前端代码中，后续应拆成可配置规则库。
- 当前不保存检测历史。
- 当前不支持团队协作与人工复核队列。
- 当前不支持图片、音频、视频检测。

## 7. 后续原型增强方向

- 增加历史记录页，展示多次检测与分数变化。
- 增加规则配置页，让运营维护风险词和改写建议。
- 增加人工复核队列，支持通过、驳回、备注。
- 增加内容发布后效果回填，形成规则优化闭环。
- 增加移动端专门布局，优化创作者手机使用体验。
