# 迭代计划：Content Safety Copilot

## 1. 迭代原则

Content Safety Copilot 的迭代重点不是堆功能，而是逐步提升三个能力：

- 风险识别更准。
- 修改建议更可用。
- 发布前流程更接近真实业务。

## 2. 版本路线图

| 版本 | 目标 | 核心能力 |
| --- | --- | --- |
| MVP v1.0 | 验证发布前安全检测流程 | 规则检测、风险等级、改写建议、自查清单 |
| v1.1 | 提升可解释性和演示完整度 | 风险词高亮、检测报告导出、更多样例 |
| v1.2 | 建立数据反馈闭环 | 检测历史、二次检测分数对比、基础埋点 |
| v2.0 | 接入 AI 语义复核 | 大模型解释、自然改写、多轮优化 |
| v2.1 | 支持团队审核流程 | 人工复核队列、审核状态、运营备注 |
| v3.0 | 扩展多模态内容安全 | 封面图、字幕、音频转写、视频截图检测 |

## 3. MVP v1.0 已完成能力

| 能力 | 状态 | 说明 |
| --- | --- | --- |

## 4. v1.1：增强展示与可解释性

### 目标

让项目更适合公开展示，也让使用者更容易看懂产品设计细节。

### 功能清单

| 功能 | 价值 | 优先级 |
| --- | --- | --- |
| 风险词原文定位 | 让用户知道具体哪个词触发风险 | P0 |
| 检测报告导出 | 方便把结果保存或发给运营同事 | P1 |
| 更多垂类样例 | 覆盖教育、医疗、法律、本地生活等场景 | P1 |
| 风险规则说明面板 | 解释每类风险的判断逻辑 | P1 |
| README 增加演示截图 | 提升 GitHub 项目可读性 | P1 |

### 验收标准

- 每个风险点能定位到具体触发表达。
- 至少新增 4 个高敏垂类样例。
- GitHub README 能在 30 秒内说明项目价值。

## 5. v1.2：数据反馈闭环

### 目标

展示“数据驱动迭代”的产品能力。

### 功能清单

| 功能 | 价值 | 优先级 |
| --- | --- | --- |
| 本地检测历史 | 用户能查看近期检测记录 | P0 |
| 二次检测对比 | 展示修改前后可发布分变化 | P0 |
| 风险类型统计 | 统计高频风险类型 | P1 |
| 本地埋点模拟 | 展示检测、复制、样例切换等关键事件 | P1 |
| 指标看板 | 展示检测次数、平均分、复制率 | P1 |

### 验收标准

- 用户可以看到最近 10 次检测记录。
- 同一内容修改后重新检测，能展示分数变化。
- 页面能展示至少 3 个核心指标。

## 6. v2.0：AI 语义复核

### 目标

从关键词规则升级为“规则初筛 + 大模型复核”的混合机制。

### 功能清单

| 功能 | 价值 | 优先级 |
| --- | --- | --- |
| 服务端模型代理 | 避免 API Key 暴露在前端 | P0 |
| 语义风险解释 | 识别规则无法覆盖的隐性风险 | P0 |
| 多版本改写 | 提供稳妥版、自然版、强吸引力版 | P1 |
| 垂类 Prompt 模板 | 针对财经、健康、教育等定制判断口径 | P1 |
| 人工反馈入口 | 用户标记建议是否有用 | P1 |

### 验收标准

- API Key 不出现在浏览器前端代码。
- 同一内容能输出至少 2 个不同风格改写版本。
- 模型输出必须包含风险原因、修改建议和不确定性说明。

## 7. v2.1：团队审核流程

### 目标

把个人发布前工具扩展为内容团队的轻量工作台。

### 功能清单

| 功能 | 价值 | 优先级 |
| --- | --- | --- |
| 审核队列 | 运营可集中处理待审核内容 | P0 |
| 审核状态 | 待审核、需修改、可发布、已驳回 | P0 |
| 运营备注 | 人工补充规则解释 | P1 |
| 团队规则库 | 团队维护专属风险词和改写模板 | P1 |
| 批量导入 | 支持一次导入多条标题或脚本 | P2 |

### 验收标准

- 内容可以在审核状态之间流转。
- 运营能对每条内容添加备注。
- 团队规则能影响后续检测结果。

## 8. v3.0：多模态内容安全

### 目标

覆盖短视频真实发布场景中的图片、字幕、音频和视频画面风险。

### 功能清单

| 功能 | 价值 | 优先级 |
| --- | --- | --- |
| 封面图 OCR | 检测封面文字风险 | P0 |
| 字幕文件检测 | 检测视频字幕和口播文本 | P0 |
| 音频转写 | 将语音转文字后检测 | P1 |
| 视频截图检测 | 抽帧识别画面风险 | P2 |
| 多模态报告 | 汇总文本、图片、音频风险 | P2 |

### 验收标准

- 支持上传封面图并识别其中的文字。
- 支持上传字幕文本并生成风险报告。
- 报告能区分文本风险和视觉风险。

## 9. 技术演进建议

| 阶段 | 技术形态 |
| --- | --- |
| 当前 | 单文件静态页面，适合快速演示 |

| v2.0 | 增加后端服务，接入模型代理 |
| v2.1 | 引入数据库，支持审核记录和团队规则 |
| v3.0 | 引入 OCR、ASR、多模态模型能力 |

## 10. 优先级建议

如果目标是公开展示和持续迭代，建议优先做：

1. README 截图和产品文档完善。
2. 风险词定位和更多样例。
3. 检测历史与分数对比。
4. 模型语义复核的设计说明。

原因：这些改动最能展示 PRD 能力、产品思考和数据迭代意识，开发成本也相对可控。
